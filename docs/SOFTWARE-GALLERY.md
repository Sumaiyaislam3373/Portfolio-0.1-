# Job Tracking software gallery

The featured Job Tracking project includes 11 actual screenshots supplied by the owner. They are optimized WebP assets at their original pixel dimensions; the original PNGs are unchanged.

Edit data/software-views.js: set each image property to an assets/projects/ path, and update the English/Bangla title and description as needed. Preserve the id, or update the associated selector references.

Screens: Dashboard; All jobs; Ready for delivery; More than 30 days; In transit; Delivered jobs; Import jobs; Trips; Trips by foreman; Foremen; Roles & permissions.

Images under assets/projects/job fit inside a wide frame without cropping. Each view has a matching English and Bangla caption. The full-size link opens the currently selected image for reading small interface text. Missing or failed images show an explicitly labeled fallback. No screenshots or business data have been fabricated.

Controls: previous/next, screen picker, pagination tabs, Left/Right/Home/End keyboard keys in the tabs, and touch swipe. No autoplay. Reduced-motion preferences are respected.

Validation: all 11 views loaded in browser checks; the full-size link followed the current selection; Bangla captions retained the selected view; 320px layout had no horizontal overflow. Source PNG filenames correspond to capture times 010424, 010434, 010450, 010503, 010513, 010521, 010529, 010538, 010547, 010558 and 010611 on 2026-11-20.
